# Networking-labs
Hands on cisco networking labs (packet tracer)
Lab 1: Inter-VLAN Routing (Router-on-a-Stick)

Tool: Cisco Packet Tracer Skills demonstrated: IP Subnetting (VLSM), VLANs, 802.1Q Trunking, Inter-VLAN Routing, Cisco IOS CLI

Objective

Design and configure a small office network with three departments (Admin, Sales, IT), each isolated in its own VLAN and subnet, using a single router with subinterfaces (router-on-a-stick) to route between them.
